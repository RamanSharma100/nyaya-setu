# 🤝 Contributing to NyayaSetu

Thank you for your interest in contributing to **NyayaSetu**! We welcome contributions from developers, legal scholars, and judicial aspirants to make Indian legal education accessible, modern, and comprehensive.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
If you find a bug or layout overflow:
- Check existing issues to avoid duplicates.
- Open a new issue with a clear title, steps to reproduce, device details, and screenshots/logs if applicable.

### 2. Suggesting Features
Have an idea for a new statutory feature, case law database expansion, or Mains rubric?
- Open a Feature Request issue describing the proposed feature and why it would benefit judicial aspirants.

### 3. Pull Request Guidelines
1. **Fork the Repository** & clone your fork locally.
2. Create a topic branch: `git checkout -b feature/your-feature-name`.
3. Follow Dart & Flutter conventions:
   - Run `flutter analyze` and resolve all warnings.
   - Run `flutter test` to verify zero test regressions.
4. Keep pull requests focused on a single feature or bug fix.
5. Provide a clear PR description detailing your changes.

---

## 💖 Sponsorship & Supporting the Project

Maintaining legal datasets, Hugging Face integrations, and Flutter updates requires continuous effort. You can support the development of NyayaSetu through:

- **GitHub Sponsors**: Support the core maintainers on GitHub.
- **Community Contributions**: Share study notes, statutory mappings, and MCQs.
- **Spreading the Word**: Recommend NyayaSetu to fellow PCS-J aspirants!

Thank you for helping us empower judicial aspirants across India! ⚖️🇮🇳
